# 提案实验完成记录

这次实验按已提交提案的整视频口径执行。训练 2,075 个、验证 446 个、测试 447 个视频，全部 119 类进入 BCE 损失，主要指标按固定 31 类计算。

三组复用原项目的 ResNet-18 分类头。冻结 ImageNet 预训练骨干，每个视频均匀采样 16 帧。随机种子为 6116，最多训练 40 轮，以验证集 mAP 选检查点，连续 8 轮未提升则早停。全局阈值由验证集 Macro-F1 选择，全部选择完成后计算 Test。

## 分类与并发动作

- **mean**，第 38 轮，阈值 0.15。Valid mAP 39.64%。Test mAP 36.26%，Macro-F1 36.55%。108 个并发视频的动作召回率 72.07%，主类预测精确率 54.01%。
- **bigru_mean**，第 39 轮，阈值 0.10。Valid mAP 38.03%。Test mAP 37.13%，Macro-F1 36.97%。108 个并发视频的动作召回率 71.38%，主类预测精确率 51.16%。
- **bigru_attention**，第 39 轮，阈值 0.30。Valid mAP 45.20%。Test mAP 38.94%，Macro-F1 37.78%。108 个并发视频的动作召回率 53.45%，主类预测精确率 69.53%。

## 模板自然语言时序定位

复用按 Valid 选定的 bigru_attention 的 ResNet-18 与 BiGRU，冻结视频特征，训练动物嵌入、动作嵌入和候选窗口评分头。查询格式为 A {animal} is {action}.，候选窗口为 16 个均匀时间单元的所有连续组合。根据最大时间 IoU 的四次方构建查询内的窗口排序目标。定位检查点按 Valid mIoU 选择。模型接收固定词表的动物和动作，未知动物使用零嵌入。

测试集共 807 条正查询，mIoU 61.47%，R@1@0.5 58.24%，R@1@0.7 48.20%。直接返回整视频的基线 mIoU 为 62.06%。
当前学习到的定位分数仍偏向较长窗口，整体效果低于整视频基线，应作为有明确局限的定位原型陈述。

整视频最佳 IoU 小于 0.5 的时间选择性子集共 334 条，定位 mIoU 22.45%，R@1@0.5 0.60%，R@1@0.7 0.60%。该子集帮助检查短动作的定位能力。

评估只取最高分预测，命中任一真实区间即为命中。界面显示的后续区间是去重后的候选，其评分没有校准为概率。此版本支持模板查询。自然措辞泛化、无目标查询拒识和多事件完整召回尚需独立评估。

## 复现与边界

新增代码位于 proposal，历史切片版结果继续由 Evaluation 页面展示，整视频结果由 Proposal 页面展示。两个版本的样本单位、预训练来源和训练配置不同，成绩应分别陈述。

特征缓存、模型权重、检查点选择记录、逐视频预测和逐类混淆计数都保存在 proposal/results。定位逐查询参考区间、预测区间和 IoU 保存在 proposal/grounding_rank_results/results.json。本次为一个固定种子的完整实验，固定划分本身仍存在既有同源素材风险。

四名成员的实际贡献及反思需依据真实工作记录填写。已有方案分配不能代替实际贡献证据。

定位开发共完成两轮。首轮 IoU 软标签 BCE 在 Valid 上退化为整视频预测；第二轮依据该 Valid 现象改用查询内窗口排序，两个版本均保留。两轮都分别计算了 Test，应披露这种开发顺序，Test 分数仅作探索性结果，不能声称为一次盲测。分类三组的检查点和阈值均在首次分类 Test 推理前固定。

CUDA 原环境的固定模型复算记录与 CPU 跨版本复算记录一并保留。PyTorch 2.14 CPU 与 2.5.1 CUDA 的 GRU 分数有小幅数值差异，靠近阈值的标签可能变化。

## 时间单元监督定位对照

新增 proposal/dense_grounding.py，以动物、动作和逐时刻 BiGRU 特征预测各时间单元的行为覆盖程度，再以区间内外证据对候选窗口排序。对重叠参考区间取并集，避免重复计算覆盖量。

完成 60 轮，仅依据验证集选模型。验证 mIoU 59.80%，整视频基线 61.20%。这轮 Test 未评估。模型预测整视频的比例为 78.62%。保持视频不变并替换动物和动作查询，最高分窗口发生变化的比例为 31.89%。

该对照已保存于 proposal/dense_grounding_results。当前结果尚不能支持定位能力改善的结论。分类任务三组独立 Test 成绩仍按上文陈述。
